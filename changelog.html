首个通过产品介绍站公开发布的版本，随附社群版 APK（Android 12+）。包含全部基础库存与数据安全能力，以及专业版五项能力（离线 OCR、客户管理、主动余额操作、预售/排产编辑、袋贴 PDF 导出）的授权门禁框架。

早期能力里程碑 内部研发阶段

下列为产品能力成型过程中的内部研发里程碑（编号对应开发阶段，并非公开发布版本号）。公开发布自 v0.2.x 起。

M1 · 数据地基

  • SQLite 数据层替换 SharedPreferences，事务落盘 + 首启迁移
  • store 拆分与备份 JSON 格式层，导出/恢复往返校验

M2 · 工程安全

  • CI 闸门（analyze + test）
  • 备份可选 AES-256-GCM 口令加密
  • 依赖巡检与本地错误日志（最近 50 条）

M3 · 体验增强

  • 浅色 / 深色 / 跟随系统三档主题
  • 首次启动 3 屏引导，可跳过

M4 · 业务增值

  • 拼配模板库（按总投入自动分配各批次重量）
  • 毛利 / 定价助手（按目标毛利率反推建议售价）

记录基于公开发布说明与开发阶段里程碑整理；如某版本描述有误，欢迎到 反馈页 告诉我们。
