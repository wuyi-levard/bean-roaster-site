隐私政策

生效日期 / 最后更新：2026 年 8 月 30 日

烘豆师（HongDouShi）是一款面向咖啡烘焙从业者的本地优先库存管理 App。本政策说明我们如何处理与 App 及本网站相关的数据。简短结论：我们不运营任何服务器，也不向开发者或第三方上传你的业务数据。

1我们收集哪些数据

App 不会收集、上传或共享任何个人信息或业务数据到外部服务器。库存、订单、客户、资金流水、配方与设置全部只保存在你自己的设备上。我们（开发者）无法看到、也无法取回这些数据。

2数据存放在哪里

所有业务数据以本地 SQLite 数据库形式存放在 App 沙盒目录内；手动备份导出为 JSON 文件，保存在应用文档目录。换机时通过导入备份恢复，数据不经由任何中间服务。

3网络与权限

Android 社群渠道构建不使用 INTERNET 权限——在系统层面即禁用数据上传。App 不含任何第三方统计、遥测或广告 SDK。对于通过应用商店分发的版本，所需的授权验证仅在你与商店之间完成，不向开发者服务器传输业务数据。

4离线 OCR 与图片

生豆袋标签识别使用设备端 PaddleOCR 推理，图片始终留在本机，绝不上传。相机原图作为溯源与人工复核来源保留在本地；识别增强副本仅在当前会话缓存，会话结束即清理，不进入备份、导出或学习样本。

5备份与加密

一键导出全部数据为 JSON；可选口令加密采用 AES-256-GCM（PBKDF2-HMAC-SHA256，20 万次迭代）。口令仅你本人持有——忘记口令无法由我们找回，这是有意的设计。

6专业版授权

社群版授权通过离线、绑定设备的授权码完成，全程无需联网。商店版的能力解锁由商店流程验证。无论哪种渠道，授权校验都不上传你的库存或订单等业务数据。

商店版的购买与支付完全由 Apple / Google 处理：我们不收集、不存储任何支付信息（如卡号、账单地址），也无法获取这些数据。退款、取消与争议请通过相应商店的流程办理。

7日志与诊断

App 仅在本地保留最近 50 条错误日志，用于你自行排查，可手动导出。这些日志保存在本机，默认不会发送给我们；如需技术支持，由你主动提供。

8本网站（介绍站）

你正在浏览的网站是纯静态页面，没有后端、不做统计、不投放广告。它仅使用浏览器本地存储（localStorage）记住你的主题与语言偏好，这些信息不与任何账号绑定、也不外传。反馈表单会将内容预填到 GitHub Issues 并新开标签页，由你登录 GitHub 后确认提交；该过程不经由我们的服务器。GitHub 侧的数据受其隐私政策约束。

9你的权利与控制

你随时可以：在 App 内导出全部数据；通过「设置 → 备份与恢复」本地覆盖恢复；卸载 App 或清除应用数据以彻底删除本机数据。由于数据从不离开你的设备，我们无力也无法代为删除或取回。

10儿童隐私

本产品面向烘焙从业者，不针对儿童设计，也不会有意收集任何年龄用户的个人信息（事实上我们不收集任何数据）。

11政策变更

本政策可能随版本更新。重大变更会在更新日志中说明，新版本发布即视为生效。本页顶部标注最后更新日期。

12联系我们

关于隐私的任何疑问，可通过邮箱 operations@levard.cn 或微信 levard2012 联系。邮件 / 微信沟通内容由对应平台隐私政策约束。
